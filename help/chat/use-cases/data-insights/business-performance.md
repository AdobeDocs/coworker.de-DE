# Übersicht über die Unternehmensleistung

<!-- FLAG: Confidence: High for the first sentence and "Best for" (carried over from analytics-overview.md). Medium for the second sentence, which summarizes the row descriptions. -->

Verwenden Sie den Adobe CX Enterprise Coworker-Chat, um zu verstehen, wie sich das Unternehmen entwickelt, warum sich eine Metrik verschoben hat, wohin sie sich entwickelt und was als Nächstes zu tun ist. Untersuchen Sie Änderungen an Ihren Schlüsselmetriken, projizieren Sie sie nach vorne und wandeln Sie Ihre Ergebnisse in für Stakeholder bereite Zusammenfassungen und wiederverwendbare Fähigkeiten um.

Business Performance ist eine von mehreren Analyse-Domains im Coworker Chat. Um alle Domains anzuzeigen, lesen Sie [Analysieren im Kollegen-Chat beginnen](/help/chat/use-cases/data-insights/analytics-overview.md#start-analyzing-in-coworker-chat) unter Analysieren von Daten mit dem Kollegen-Chat.

**Am besten geeignet für:** Analyst, Business-Anwender

## Voraussetzungen

Um die Anwendungsfälle auf dieser Seite zu verwenden, benötigen Sie Folgendes:

* Mit dem Coworker Chat wurde eine Verbindung zu Ihren Customer Journey Analytics-Datenansichten oder zu Adobe Analytics Report Suites hergestellt. Siehe [Erste Schritte mit der Datenanalyse mit dem Coworker Chat](/help/chat/use-cases/data-insights/analytics-chat.md).
* Zugriff auf die Datenansichten oder Report Suites anzeigen, die Sie analysieren möchten. Der Coworker Chat übernimmt Ihre Berechtigungen von Customer Journey Analytics oder Adobe Analytics.

## Tipps für bessere Ergebnisse

* Benennen Sie die Metrik und den Zeitraum der Änderung, die Sie untersuchen möchten. Die Ursachenanalyse funktioniert mit einer bekannten Metrik über einen bekannten Zeitraum.
* Fragen Sie nach den beitragenden Dimensionen, wenn Sie eine Aufschlüsselung einer Metrikänderung wünschen.
* Fordern Sie bei der Projektion von Metriken einen Prognosehorizont an, z. B. „Nächste 30 Tage“.
* Geben Sie die Zielgruppe für eine Zusammenfassung an, z. B. die Führung oder das Marketing-Team, und fordern Sie einen Folienüberblick an, wenn Sie die Ergebnisse präsentieren möchten.
* Schließen Sie zunächst eine Analyse ab und bitten Sie dann den Kollegen-Chat, sie als Kenntnisse zu speichern. Geben Sie der Kenntnis einen klaren, beschreibenden Namen und notieren Sie, wie oft Sie sie wiederverwenden möchten.
